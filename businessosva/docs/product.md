# Product: Business OS

## Concept

One connected operating system instead of ten separate SaaS tools. Every record links to the others:

```
Lead → Client → Projects → Tasks → Deadlines → Calendar
                   ├── Documents
                   ├── Finance (invoices, budget)
                   └── Team
```

The **AI Daily Brief** reads all of it and surfaces the 3–7 things that need a decision today, instead of a notification feed.

## Navigation

| Group | Pages |
|---|---|
| Home | Dashboard |
| Sales | CRM (leads), Clients (existing customers), which are kept separate |
| Delivery | Projects, Tasks, Calendar |
| Business | Finance, Documents, Team |
| Intelligence | AI Daily Brief |

## Pages at a glance

| Page | Answers | Key parts |
|---|---|---|
| Dashboard | What's happening today? | Brief card + focus mode, Today (schedule and my tasks), Attention needed, My results, Recent activity |
| CRM | Where is every deal? | Pipeline stages as filters, lead list, lead detail with stepper, history, follow-ups, meetings, proposals, notes, documents, **Convert to client** |
| Clients | How is each relationship? | Health, open balance, lifetime value; Client 360 with projects, tasks, finance, docs, timeline |
| Projects | Are we delivering? | List / board views, project detail with milestones track, risk callout, team, budget, activity |
| Tasks | What's due? | Today / week / overdue views, project, person, priority and status filters, inline priority and assignee menus, task drawer |
| Calendar | When? | Month / week / day, type filters, events linked to client, project and task |
| Finance | Are we getting paid? | KPIs, revenue chart, receivables aging, invoice list, invoice detail with reminder / mark paid |
| Documents | Where's the file? | Contracts, proposals, invoices, other; every file linked to a client and project |
| Team | Who's doing what? | Role-specific performance (sales, delivery, makers, finance) |
| AI Daily Brief | What do I need to know and do? | Ranked attention items with reasoning, today with prep notes, priorities, progress, signals, filtered-out updates |

## Interaction principles

- Every entity name is a link, and **Back** always works.
- Tasks and events open in a side drawer, so the list stays in view.
- Attention items resolve themselves: finishing the blocker, getting paid or converting the lead removes them from the brief and the dashboard.
- Destructive or state-changing actions show a notification with **Undo** or a **next step**.
- Focus mode walks through the day's decisions one at a time.
